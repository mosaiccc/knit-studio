# 织间 · Knit Studio

中文编织设计工具：从图片或手绘花样，到尺寸换算与可导出的编织图解。

## 使用

图片在当前设备内处理，不上传；工程和共享提花库自动保存在当前浏览器，优先使用 IndexedDB。旧版单作品会自动迁入工程库。可下载 `.knit.json` 工程备份、`.knit-motif.json` 独立提花备份，或在「我的工程」下载全部工程与提花库。

本地使用：安装 Node.js 24 或更新版本后，双击本目录中的 **start-knitting.cmd**，会在后台启动工具并打开浏览器。电脑重启后，也先双击这个文件；重复打开会使用已经运行的工具，不会重复启动。无须安装第三方依赖。

工具地址固定为 `http://127.0.0.1:4173/`。在原来使用的浏览器中打开此地址，可继续使用原有工程和提花库；不同浏览器的数据相互独立。如果页面提示“拒绝连接”，请先双击启动文件再刷新页面。

也可在本目录运行 `npm start`，保持该命令窗口开启，再访问上面的地址。直接双击 HTML 不适用，因为浏览器会限制本地 JavaScript 模块。

## GitHub Pages 发布

源码仓库保持私有，是否可开启 Pages 取决于 GitHub 账号套餐。仓库 Settings → Pages 中选择 GitHub Actions 作为来源，然后在 Actions → Deploy Knit Studio to GitHub Pages → Run workflow 手动发布。工作流使用 Node.js 24，先生成资源清单并运行全部测试，再仅发布 `dist` 目录。

网页可以公开访问，浏览器所需的 HTML、CSS 和 JavaScript 也可由访问者读取。你创建的工程和提花只保存在自己的浏览器中，不会自动写入仓库。首次从本地版转到 Pages 时，请下载全部备份，再在新网址导入；两个网址的数据相互独立。

每次修改后手动运行同一个发布工作流。工作流成功后，以仓库 Settings → Pages 中实际显示的网址为准。iPad 可用 Safari 打开，无须 clone 或运行 Node.js。

## iPad 离线使用

首次安装和下载工具需要联网；完成后可以在断网、电脑关机的情况下打开主屏幕上的织间，继续绘制、保存和导出。

1. 在 iPad Safari 打开私有在线地址并登录，点击分享 → 添加到主屏幕。若显示“作为网页 App 打开”，保持开启。
2. 从新添加的主屏幕图标打开织间，保持联网，等待页面显示“离线已就绪”。可点击“iPad 安装与离线使用 → 检查与准备离线”核对。
3. 在这个主屏幕应用内通过“我的工程 → 导入工程”导入电脑的备份。不要假定 Safari 标签页和主屏幕应用共享作品。
4. 出门前开启飞行模式，关闭并重新打开织间，确认能打开作品。需要导入的照片和文件应事先下载到 iPad 本机。

工程、提花和图解保存在当前浏览器/应用的 IndexedDB，不自动跨设备同步。请定期下载“全部备份”；清除网站数据、卸载或系统清理可能移除缓存与作品。保留存储请求由浏览器决定，获准后仍应备份。已转换的提花会保存，原始照片需在下次框选时重新选择。

离线功能覆盖绘图、图片转换、版型编辑、密度换算、本地备份导入和图解/文字教程导出。打印机、云端文件及外部参考链接可能仍需网络。新版本会在后台准备，关闭所有织间窗口再重新打开后启用，不会强制刷新编辑中的页面。

维护源码时，在每次修改 `dist` 后运行 `npm run build:offline`，再运行 `npm test`。离线清单完整性测试会拒绝过时的生成文件。服务工作线程按版本缓存固定资源，验证资源类型与内容，不缓存登录页或任意网络请求。

## 完整流程

0. **新建工程**：顶部「新建工程」填写名称，按分类选择整件衣服款式、尺寸和试织密度，预览全部裁片后创建。提供 16 种款式，自动配好前片、后片、左右袖及适用门襟。「我的工程」可以切换、导入和备份多个工程，原工程保留。最多 30 个工程，提花库共享。

1. **提花设计**：导入 JPG、PNG、WebP 等图片，设定 4–200 针 × 4–240 行以及 2–32 种线色；透明区域使用底色。或从郁金香、北欧雪花、菱格与空白画布开始。「新建提花」绘制另一个花样，「保存提花」独立命名保存，「另存为」保留副本。提花库最多 100 个花样，可继续绘制、单独下载与导入。
2. **手工绘制**：画笔 B、填充 F、橡皮擦 E、吸色 I，支持拖动画线、左右对称、左右翻转、缩放、针目预览及撤销重做。橡皮擦使用调色盘第一个底色。
3. **版型设计**：31 种裁片模板，按套衫前后片、马甲前后片、开衫前后片、袖片、门襟与收边、配饰、基础裁片分类。点击「添加裁片」自由组合前片、后片、左右袖等，每个工程最多 12 片；可重命名、复制、移除，并支持撤销恢复。新工程按所选整件款式创建完整裁片组合，之后更换单片版型不会自动添加其他裁片。旧工程保留原有裁片组合。点击裁片的「编辑」按钮，分别修改平铺宽度、长度、肩宽、领宽、领深、袖窿等适用参数。试织密度由全部裁片共用。也可以点击版型上的宽高及肩宽标注编辑。「插入文字」可添加多行备注，调整字号和颜色；拖动定位，双击编辑，也可用方向键微调。各片尺寸、提花、手绘、针法和文字独立保存，支持撤销和重做。
4. **编织图解**：在「图案放置」中从提花库加入多个花样，拖动定位或填写右侧起针、底部起行（花样右下角的位置）。同一花样可放置多次，支持翻转、不绘制底色、调整叠放顺序、移除与撤销。每片最多 100 个放置实例，按裁片分别保留。放入工程的是独立快照，之后编辑或删除库中原稿不会改变它。旧版重复铺满和单幅居中模式仍可选。在图解中也可以直接画笔绘制、填充、擦除、吸色、左右对称、撤销重做；手绘在所有提花上层。修改尺寸时暂时不可见的覆盖仍保留。行号自下往上，针位自右往左。
5. **导出**：默认可将全部裁片一起导出为 PNG 高清图、SVG 矢量图或带尺寸与文字的版型 SVG，也保留当前裁片和单独提花的导出选项。打印页提供全部裁片对照、逐片总览、逐行针数和最多 60 针 × 80 行的细节分页，可在浏览器打印对话框中另存 PDF。完整图解包含各片的手绘与文字标注，作品 JSON 保存全部裁片并可再次编辑。

编织图解页同样并列展示全部裁片，点击需要编辑的裁片后直接绘制或放置提花。各片下方可展开逐行针数。窄屏中裁片纵向排列。

**提花尺寸与比例**：提花设计的「画布设置」默认锁定原画布比例。修改横向针数或纵向行数时，另一方向自动联动；点击「应用画布尺寸」后，整幅提花同步放大或缩小，支持撤销和重做。也可直接填写横向、纵向实际厘米数，按当前工程的每 10 cm 试织密度换算为整针、整行，并显示取整后的实际尺寸。比例以已应用画布为准，另一轴最多有半格取整误差；关闭锁定后可独立修改宽高。最大 200 针 × 240 行，超限不会应用。放大保持原线色，缩小可能减少细节。尺寸调整只改变当前草稿；保存提花后才能更新库中原稿，已经放置的独立图案不变。

**画笔与橡皮擦大小**：在提花设计或编织图解中，选择画笔或橡皮擦后，工具栏下方会显示大小滑块与数字输入，可设为 1–25 格，每次覆盖对应的方形区域（例如 5 × 5 格）。两种工具分别记住大小，刷新后继续使用。鼠标移到画布会显示覆盖范围；连续拖动、左右对称、撤销和重做均支持大笔刷。裁片镂空保持不变，橡皮擦仍使用当前底色；填充、吸色和针法工具保留原有用法。

**针法符号**：图解页左侧「编织针法」提供下针、上针、空加针、右倾二并一、左倾二并一、滑针（线在后）、扭下针和扭上针。选择后在当前裁片网格内单击或连续拖动，支持左右对称、撤销与重做。按 S 可回到针法工具；「擦除针法」仅擦符号，「清空本片针法」可以撤销，提花颜色会保留。针法随裁片复制与备份，完整图解 PNG、SVG 和打印均带符号及实际使用的中文图例，单独提花导出保持原花样。右倾三并一已从可选菜单移除，旧工程中的该符号仍可读取和导出。

**上下对称绘制**：编织图解工具栏在左右对称旁新增上下对称按钮，两者同时开启可四向绘制。画笔、橡皮擦、填充、针法绘制和擦除均支持，镜像围绕当前裁片完整网格的中心，各点独立跳过领口等镂空；大笔刷范围预览同步镜像，一笔可以一次撤销。左右填充同时补齐对称行为。针法只镜像位置，保留所选针法种类。

**文字编织教程**：点击「导出图解 → 文字编织图解」，选择从下往上或从上往下、全部或当前裁片，以及第一行正反面。按各片分别平织生成工程密度、尺寸、近似中文线色与色号、起针、逐行配色与针法、轮廓增减针目标、分段和收尾，并带上原文字标注。实际工作行号与原图行号同时标出，反面针法按原图例转换，无符号格默认平针。可直接编辑预览并下载 UTF-8 TXT 或可打印 HTML；修改选项只标记待生成，点击重新生成才替换现有文字。图解中的并针、空加针按实际消耗和形成针数核对，不与轮廓重复加减；领口各段分别核对，不能跨空格抵消。缺少连接、肩斜短行、袜跟、缝合等信息时，教程会明确指出需要补充的工艺。未应用轮廓草稿不会影响已应用图解，导出会提示。所有生成在本地完成。

**图片框选与细节保留**：上传图片后，可在原图上拖动矩形框选单只小羊等花样，支持移动选区、8 个边角调整柄、方向键微调、像素坐标输入和 100%–300% 原图缩放。只有框内区域参与转换和取色，右侧等比放大显示像素预览。可调整 4–200 针、4–240 行和 2–32 种线色；默认开启「保留小面积深色细节」，减少少量黑色被大面积绿色合并的问题。应用后建立独立的新提花草稿，支持逐格修改、单独保存、撤销和重做；取消不改变画布。已有花样保留。本次页面打开期间可用「重新框选原图」继续裁剪，刷新后需重新上传原图。选框内的背景、织纹和阴影也会转换，可在画布中继续整理；此功能不自动还原照片中的实际编织针目。

**自定义裁片轮廓**：在「版型设计」选择裁片，点击「调整轮廓节点」。拖动圆点移动节点；点击边线，再拖动绿色菱形控制点调整弧度。支持增加节点、删除节点（保留 3–80 个）、拉直当前边和恢复原版型；均可撤销重做。焦点在节点或控制点上时可用方向键微调，Shift 加大步长。轮廓在当前宽高范围内编辑，并同步决定图解中的有效针格和逐行针数。每片轮廓独立保存，复制、刷新、备份及全部裁片导出均保留。

**自由绘制版型**：点击「自由绘制」，可在当前轮廓上画直线、三点弧线、自由笔画，或删除线段；也可以「清空线段重画」。直线可拖动绘制，也可依次点起点和终点；弧线依次点击起点、终点和弧度控制位置。选择工具可移动端点和弧度控制点，长边可先分割后局部修改。新线端点会吸附到已有端点，红色圆点表示尚未连接的开口。所有线段组成一个闭合轮廓后，点击「应用到裁片」更新针格与逐行针数。每次绘制、删线和应用都可撤销重做。未闭合的草稿也随裁片自动保存，可切片或刷新后继续绘制；尚未应用时，图解与图片导出使用最后一次已应用的轮廓，工程 JSON 同时保留草稿。每个轮廓最多 80 段，适当简化自由笔画以保持可编辑。

自定义轮廓按宽高比例缩放；肩部、领口等改用拖动节点调整，模板参数仅作参考。恢复原版型后，可重新按肩宽、领深等参数生成。更换当前裁片模板会恢复所选模板轮廓，可以撤销。轮廓形状不自动生成收放针教程。

**新增内置提花**：提花设计页的「小羊与常见花样」提供站立小羊、跳跃小羊、低头吃草、坐着的小羊、卷角小羊、侧卧睡觉、回头小羊、母子双羊，以及小爱心、小雏菊、四叶草、郁金香花边。选用时使用完整原始尺寸和配色，作为新草稿打开，支持撤销。可逐格改色和绘制，再点击「保存提花」独立存入库中，随后到「编织图解 → 从提花库添加」安排位置。

符号按织物正面效果标注，平织反面行请结合图例中的对应针法阅读；增减针符号不会自动改变裁片针数。针法含义参照 [Craft Yarn Council 图例](https://craftyarncouncil.com/standards/knit-chart-symbols)和[针法缩写](https://craftyarncouncil.com/standards/knitting-abbreviations)，具体符号以本工具随图导出的图例为准。

## 支持版型

新建工程按整件款式分类：

- **套衫**：圆领套衫、V 领套衫、半高领套衫、落肩套衫、插肩套衫，均含前后片和左右袖。
- **马甲**：圆领马甲、V 领马甲、开衫马甲。开衫马甲含左右前片、后片、左右门襟。
- **开衫**：圆领开衫、V 领开衫，含左右前片、后片、左右袖、左右门襟，共 7 片。
- **夏季上衣**：吊带前后片。
- **配饰**：帽子、斜角围巾、筒袜、五指筒款手套。
- **基础设计**：直筒矩形。

单片模板共 31 种，以上各款的前后片、袖片和门襟都可在「添加裁片」按分类选择。

**梯形袖子**：在「版型设计 → 添加裁片 → 袖片」中选择，也可将当前裁片更换为梯形袖子。无袖山、上宽下窄，默认袖根宽 36 cm、袖口宽 18 cm、袖长 48 cm，三项可分别调整；袖口宽须大于零且不超过袖根宽。版型图标注上下端尺寸与密度换算针数，图解从袖口向袖根逐渐加宽，支持提花、针法、自由修改轮廓与导出，工程备份保留袖口参数。

**开衫门襟**：新建时填写衣身平铺宽度（含扣合后的门襟）与门襟宽度，每片前片宽度为（衣身宽度 − 门襟宽度）÷ 2。左右门襟分别作为独立直条，默认宽 3 cm，长度按各前片开口边的直线、斜线或圆领弧线估算。创建后宽度、长度、提花、针法和文字可分别编辑与导出。门襟扣眼和连接工艺需按设计自行标记。袖山与接缝可结合试织继续调整。


## 尺寸规则

针数 = 四舍五入（宽度 cm × 每 10 cm 针数 ÷ 10）；行数同理。界面和导出同时标出目标尺寸与取整后的实际尺寸。完整裁片最多 400 针 × 600 行，超限会提示，不会修改用户密度。切换版型会载入该版型默认尺寸，保留试织密度。

肩宽按两侧肩端的水平距离计算，开衫前片按半片。肩宽必须大于领口宽度且不超过裁片宽度，会影响轮廓、肩部针数和逐行针数。旧工程未填写肩宽时从原轮廓推导，并保留原裁片数据。

版型是可调整的平面裁片参考，而非完整成衣教程。袜子不自动设计足跟和转跟；五指手套展示掌片与指筒，连接、围度和分指需实际试织；其他版型的缝合与收放针织法同样需要实际安排。

## 文件与验证

- `dist/` 为可直接静态托管的应用。
- `dist/core/` 为网格、版型和项目校验算法。
- `tests/` 包含算法、编辑交互、存储、导出和本地启动测试，运行 `npm test`。
- `docs/` 保存设计方案与实施计划。
