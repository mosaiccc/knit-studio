# 图片框选与细节保留

目标：用户能在绿色毛衣照片中框选一只小羊，只转换选区，保留少量深色细节，在提花画布继续设计。仅更新本地版本。

已确认原因：原导入直接把整图平滑缩为目标网格，加权中位切割再把稀少黑色和大面积绿色平均；6 色甚至 8 色可能没有深色代表。

设计：上传后打开原图/像素预览对照窗。默认可在原图拖出矩形，支持反向拖选、8 个调整柄、移动选区、全图复位和像素坐标微调。预览、自动比例与取色均只使用选区。提供针数、行数、颜色数和默认开启的细节保留选项，确认后才替换当前画布，并作为独立新提花草稿，不改已保存花样；一次撤销可恢复。取消不修改工程。原图在本次页面会话中可重新框选。

- [x] `core/image-crop.js` 与 `image-crop-editor.js`：几何校验和可访问的鼠标/键盘裁剪交互；先覆盖边界、反向、拖动末端与取消回归。
- [x] `core/image-import.js`：从高分辨率裁区提取有限色板，再聚合成针格；对低频高对比深色保留、透明合成、确定性、无虚构黑色、输出颜色上限及性能做测试。
- [x] `image-import-modal.js`：独立原图与像素预览、坐标与参数输入、实时预览和错误处理。采样长边不超过 1024、总像素不超过 1M；严格校验画布 4–200 针 / 4–240 行。
- [x] `app.js`：替换旧图片导入，维护已上传原图会话入口，防止重复异步上传覆盖，应用使用完整撤销快照。
- [x] `styles.css`：宽屏并列、窄屏上下的裁剪窗，明确选框、深色细节开关、使用中的线色和应用范围。
- [x] 浏览器验证：先备份用户工程；用独立验证工程上传图片，框选小羊、移动/缩放框、调整颜色与针行、应用和撤销、导出；检查黑色和裁区范围，清理临时工程，核对原工程及提花未变化。若用户提供当前原图路径，再用原图复核。
