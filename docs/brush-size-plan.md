# 可调画笔与橡皮擦

用户要求画笔、橡皮擦均可调整大小。应用于提花设计和编织图解的颜色绘制，沿用方形针格；保留现有底色擦除和裁片镂空规则。

- 核心：`drawLine`、`paintChartLine` 第八参数为 `size=1`，范围 1–25 格；每个落点覆盖 size × size 方块，偶数尺寸向右下偏半格。对称模式反射实际覆盖格，边缘与镂空裁切，连续拖动不间断。
- 交互：每笔锁定大小；指针悬停显示实际覆盖范围，离开隐藏。填充、吸色、针法和移动图案保留原有语义。
- 界面：画笔或橡皮擦选中时，工具栏下方显示大小滑块、精确数字和「N × N 格」。两种工具分别记住大小，刷新继续使用；尺寸设置不作为作品修改或撤销记录。
- 验证：先覆盖大小、对称、裁边、孔洞、连续笔画与撤销事务测试，再进行独立临时工程浏览器检查。备份并核对用户现有工程和小羊画布，不使用原画布试画。仅更新本地版本。
