# 上下对称与文字编织图解

目标：编织图解页可上下镜像绘制，并从当前工程导出可编辑的中文逐行教程，支持从下往上或从上往下编织。

1. 对称绘制：新增独立上下开关，与左右对称同时开启可四向绘制。镜像围绕当前裁片完整网格中心，画笔、橡皮、针法及填充均跳过裁片镂空。大笔刷预览与实际覆盖一致，每笔一次撤销；提花设计页继续保持现有控件。
2. 教程核心：读取每片已应用轮廓、手绘、独立提花放置、针法和文字。按所选方向遍历图解，保留原图行号，并另标实际编织行号。默认平织往返，可选择首行正面或反面；无符号格按平针处理，正反面针法分别转换。
3. 针数核对：有效格不含镂空，断开的区段分开叙述。符号按消耗针数/生成针数核对，轮廓变化与并针不重复计算。普通边缘变化写出左右加减针数；分段、连接及不匹配处给出具体待确认内容，不凭空补出缝合、袜跟或引返工艺。
4. 导出界面：原导出菜单增加文字图解，选择全部/当前裁片、编织方向、首行正反面，生成完整预览。预览文字可修改，下载 TXT 或可打印 HTML 保留修改；改变选项后需重新生成，防止文件方向与正文不一致。
5. 验证：算法与交互测试覆盖上下/四向、奇偶笔刷、镂空、填充、针法、工作顺序、正反面转换、颜色段、形状变化、分段、符号针数及数据不变。浏览器临时工程实际绘制、撤销、两方向下载并核对文件；原工程完整备份比较。

依据：现有图例和 Craft Yarn Council 正面外观图解符号规则。工程与图片继续本地处理，本次不发布在线版本。
