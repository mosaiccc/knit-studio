# 织间 · Knit Studio

目标：提供中文浏览器编织工作台，完整连接图片转像素提花、手绘、版型参数与密度换算、图解导出。用户已选择优先完整流程。

采用无构建依赖的 HTML、CSS、JavaScript 模块与 Canvas/SVG。图片只在浏览器内处理，项目保存在 localStorage，可通过 JSON 导入导出。界面为暖白画布、墨灰文字、陶土粉强调色，工作区包括左侧图片/颜色面板、中间编辑画布、右侧版型预览。

功能：图片缩小取样与限色，画笔/擦除/吸色/区域填充，撤销重做、镜像绘制、网格缩放与重设。提供全部 15 种版型，宽高、领宽领深、袖窿等参数和每 10cm 密度；根据版型生成逐针逐行的裁片掩码，将提花重复或居中铺到版型上。尺寸标注可点击编辑。输出 SVG、PNG、可打印页面（浏览器另存 PDF）以及项目 JSON。

正确性：宽度针数=四舍五入(cm×每10cm针数÷10)，高度行数同理；输入需为有限正数；标注名义尺寸以及取整后的实际尺寸。版型是可调整的平面参考，袜子为筒袜不含足跟，五指手套由掌片和手指筒组成，避免宣称自动生成专业成衣教程。

模块边界：core/pattern.js 负责网格与颜色算法；core/garments.js 负责模板、几何与密度；export.js 负责可移植图解；app.js 与 editor.js 负责状态与交互；styles.css 负责响应式布局。

验证：对颜色、填充、尺寸换算、模板几何和逐行计数做 Node 测试；浏览器检查画笔、导入、参数修改、保存恢复、导出及小屏排版。
