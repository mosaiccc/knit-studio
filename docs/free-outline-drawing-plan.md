# 自由绘制轮廓与三款小羊

本次本地更新将原有节点调整扩展为可画直线、三点弧线、自由画笔以及选择、删除线段的绘图工具。

- 每片保存独立 outlineDrawing 草稿，线段由归一化起点、终点、弧线控制点和类型组成。草稿允许开口、分支和多段；切换、复制、刷新与工程备份均保留。
- 从当前模板或自定义轮廓开始。删线真实留下开口，可分割现有线段后删除局部。绘制端点吸附，未连接端点用红点提示；支持清空从头画及重载当前轮廓，全部可撤销。
- 完整闭合的单个轮廓才能应用。应用转换为已有 customOutline，统一影响图解掩模、逐行针数与导出。草稿未应用时图解使用上次应用的轮廓，并在界面和导出窗口明确提示。
- 拖动选中线段端点及弧度点可继续修改。未完成线段/弧线按 Esc 取消，已完成操作独立保存且可撤销。
- 新增侧卧睡觉、回头小羊与母子双羊三款原生提花；原有九款保留。

实现边界：core/outline-drawing.js 负责几何与闭合校验；drawing-editor.js 负责鼠标和键盘交互；app.js 集成草稿、工具、状态、撤销与导出提示。核心和交互分别先验证失败测试再实现，最后浏览器验证删边/补线/弧线/画笔/应用/刷新/单片隔离和原有工程保留。
