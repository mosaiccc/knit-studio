# 衣服款式分类与门襟裁片

目标：新建工程按完整衣服款式选择，分类展示常见套衫、马甲和开衫等；按款式一次生成独立前后片、袖片及门襟，后续逐片编辑与导出。

- 裁片目录保留原 15 个模板的标识、默认尺寸与轮廓，新增圆领/V领马甲前片、圆领开衫前片、开衫后片、开衫马甲前片、半高领后片、落肩前后片与直袖、插肩前后片、左右门襟。裁片按套衫、马甲、开衫、袖片、门襟与收边、配饰、基础裁片分类。
- 整衣目录提供 16 款：五种套衫、三种马甲、两种开衫、吊带上衣、四种配饰及基础矩形。创建显式裁片数组，不调整旧工程的裁片组成。
- 新建窗口提供分类、款式卡片、尺寸与密度输入、即将生成的裁片预览。开衫增加门襟宽度，衣身宽度包含扣合门襟：左右前片各为（衣身宽度－门襟宽度）÷2，门襟扣合后前片总宽等于后片。门襟长度按前片实际开口边线估算，创建后独立调整；扣眼不自动生成。
- “添加裁片”、图解版型和预览下拉按类别分组；版型设计侧栏使用折叠分类。肩宽半片标注和半高领高度对所有新模板一致，SVG与文字导出适配。
- 验证新旧模板轮廓、镜像、门襟尺寸与密度、所有款式组合、独立裁片、导出及旧数据兼容。浏览器验证按类别新建马甲/开衫、独立编辑门襟、同页图解与导出，测试前后备份比较保留原工程。
- 仅更新本地版本。
