# 自定义轮廓、针法与内置提花

用户选择通过拖动轮廓节点调整曲线。此次只更新本地工具。

- 自定义轮廓随单个裁片保存，节点使用相对坐标；每条边使用二次贝塞尔控制点。调整尺寸或密度后按比例重新计算针格和逐行针数。旧工程默认使用原模板。
- 在版型工作台选择「调整轮廓」，圆点移动节点，菱形控制点调整弧度；支持增加节点、删除节点、拉直当前边、恢复模板以及撤销重做。其他裁片仍同时显示。文字编辑与轮廓编辑分别使用对应工具。
- 更换模板时清除该片自定义轮廓，可撤销；复制裁片、备份、导入、刷新均保留自定义轮廓。版型与图解导出使用相同轮廓。
- 针法菜单增加扭上针、移除右倾三并一。旧工程中的三并一保持可读和导出，避免丢失之前绘制的数据。
- 内置提花新增五种姿态小羊和四种常见图案，各自使用完整尺寸与色板。选用后作为新草稿，可撤销、继续绘制和独立保存，不覆盖已有库中原稿。

实施分工：核心轮廓及存储、针法、提花目录分别实现；主任务集成轮廓交互、导出与页面入口。

验证：先验证新增核心行为的失败测试，再实现；覆盖曲线与针数、缩放、单片隔离、工程往返、节点拖动提交与取消；全量测试通过后在浏览器验证拖动、撤销、保存刷新、内置图案保存与放置。浏览器使用独立验证工程，并备份用户现有数据。
