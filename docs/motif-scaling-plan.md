# 提花尺寸与密度换算

目标：修改画布尺寸时整幅提花随之缩放，默认保持原始宽高比例；同时提供针数/行数与实际厘米尺寸的双向输入。

- 新增独立尺寸模块。最近邻重采样保留已有线色，放大完整图案，缩小按像素中心采样。旧裁切/扩展工具保持原语义，不再用于画布设置。
- 画布设置显示四个字段：横向针数、纵向行数、横向实际尺寸、纵向实际尺寸。厘米尺寸分别按项目的每 10 cm 针数和行数换算。
- 默认锁定比例，以已应用画布的宽高为基准，另一轴取整到针/行；关闭后可独立调整。超出 4–200 针或 4–240 行时显示错误且禁止应用。
- 输入目标值只更新待应用控件。应用时结束当前笔画，读取最新图案并一次性缩放，保留撤销重做与独立提花库保存语义。
- 不改变工程密度和已经放置的独立图案。密度调整后重新计算厘米显示。
- 验证纯尺寸计算、重采样、四字段联动与错误恢复，并在临时工程验证放大/缩小、厘米输入、撤销重做和刷新。验证前后导出完整备份，确保原工程与提花库保持不变。
- 仅更新本地版本。
