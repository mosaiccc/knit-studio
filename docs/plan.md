# 编织工具实施计划

目标：将图片或手绘图案映射到可调尺寸的编织版型，导出可阅读图解。

1. 在 dist/core/pattern.js 实现纯函数网格、填充、变换和限色算法；在 tests/pattern.test.mjs 先测试填充边界、透明像素、尺寸变化和颜色约束。
2. 在 dist/core/garments.js 实现 15 个版型、参数校验、厘米/针行换算、裁片掩码和逐行统计；tests/garments.test.mjs 验证参考数值、几何有效性以及边界。
3. 在 dist/index.html、styles.css、app.js、editor.js 实现工作台、可编辑 canvas、图像解码/导入、调色、模板切换、参数控件和本地保存。
4. 在 dist/export.js 生成可打印完整图解与 SVG/PNG 导出；JSON 项目可重载，导入需结构校验。
5. node --test tests/*.test.mjs 验证计算；node --check 验证模块语法；启动本地服务并通过浏览器检查主要交互。
6. 注册私有站点，保持源代码在当前工作区，验证发布结果后交付在线地址与本地运行方式。

## 后续：完整图解绘制与文字标注

1. 完整图解支持画笔、填充、擦除、吸色与镜像；裁片外的空白单元不可绘制。按每个版型保存以右下针行为原点的手绘覆盖，修改尺寸时保留已有覆盖；生成图、预览、保存、导出均采用覆盖后的图案。
2. 增加版型文字标注：插入、多行编辑、字号与颜色、拖动及键盘移动、删除。使用版型画布归一化坐标，并按版型分别保存。支持撤销重做。
3. 旧版作品兼容载入；新备份包含手绘覆盖和文字。完整 SVG/PNG 和打印页面保留文字，另提供独立的版型标注 SVG。
4. 单元测试验证遮罩、针位坐标、填充、旧数据迁移、文字转义及导出；浏览器验证连续绘制、编辑文字、拖动、刷新恢复与导出。
