# 肩宽与前后片同页工作台

目标：衣身版型有独立肩宽尺寸，前后片在版型设计及编织图解中同时显示、分别编辑、一起备份和导出。

设计：工程保存 pieces 数组与 activePieceId，每片包含 id、label、garmentId、measurements、chartEdits、annotations、motifPlacements、arrangement、placement、fabricColor。现有顶层裁片字段作为当前编辑片的兼容接口，保存与切换时同步。试织密度、提花草稿与共享花样库保持工程级。旧工程迁移保留原裁片；衣身自动补齐对应前后片，开衫三片，配饰和袖片仍单片。每片放置实例、排列方式、底色、文字与手绘互相独立。

肩宽：衣身前后片为两侧肩端的水平距离，开衫半片为该片肩端至门襟侧的宽度。肩宽大于领宽且不超过裁片宽度；未提供时按旧轮廓推导，保留旧图形。轮廓、遮罩、逐行针数和导出都应用肩宽。

实施与验证：
- [x] garments.js 增加肩宽推导、默认值、字段、几何和参数约束。先验证旧轮廓兼容、宽度改变、开衫镜像及非法范围。
- [x] core/pieces.js 和 project.js 迁移、验证、保存与切换裁片；测试同版型双片数据独立，旧版迁移和 JSON 往返。
- [x] app.js 同时渲染前后片卡片，点击选中编辑，侧栏跟随当前片；肩宽标注和精确输入；完整图解在同页展示全部片。styles.css 让桌面并排、窄屏纵排。
- [x] export.js 添加所有裁片合并 SVG/PNG 和打印，保留单片导出。单片肩宽尺寸清楚标示。
- [x] 143 项测试、语法及差异检查通过；浏览器验证肩宽修改、切换前后片、分别手绘、立即刷新、合并导出与开衫三片显示。临时工程已备份移除，用户原工程保留并恢复。
